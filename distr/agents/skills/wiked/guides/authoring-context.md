# Authoring Context

Load this guide for contextual preparation in page creation or revision, permanent diagram authorship, assisted indexing, and maintenance, including read-only maintenance review. It is the common authority for this preparation; it does not require loading the modeling guide merely to prepare context. Query exports retain `query.md`'s selective preparation; loading D2 for a temporary export does not itself require this guide.

## Prepare

Complete this preparation before analyzing content or proposing authorship decisions, not merely before writing:

1. Resolve `navigation.context_file` from the instance contract relative to the consumer's `wiki/` root and read that file. It governs canonical vocabulary and domain meaning, not operational facts.
2. When `navigation.authoring_file` is declared, read the configured local authoring reference. Its instance-local review criteria, guidance, and examples may reference the contract or canonical terms but cannot redefine deterministic structure or domain meaning. It is not operational evidence.
3. Read the configured root index, then navigate progressively through only relevant top-level indexes, affected pages, and pertinent references for the current objective. Do not load the entire wiki or intent map indiscriminately. This preparation does not itself require the intent map; the calling workflow determines when its selective map rules apply.

If the configured context is absent in an existing instance, stop normal authorship and report the gap. Do not infer replacement vocabulary from pages or sources, silently create the context, or treat an incomplete instance as a new initialization. Recovery requires an explicitly authorized scope and closed grill before writing. Only explicitly requested initialization or migration uses the bounded exceptions defined in `setup.md`; normal preparation does not require loading that guide.

Preparation authorizes no edits. Read-only review still needs no grill; governed-content changes remain subject to `grill.md`.

## Local Acronym Presentation

Expanding acronyms at first occurrence is an optional instance-local editorial criterion, not a universal requirement or an automatically validated rule. If an instance chooses to adopt it for wiki pages, propose first occurrence per page as a starting point for human approval, not a preset obligation. Keep the approved presentation criterion in the local authoring reference and canonical meanings in the configured context; reference those meanings rather than maintaining competing definitions. This option does not require creating an authoring reference when no local criterion has been adopted. Creating or changing the criterion follows the governed maintenance workflow in `maintenance.md`.

Do not automatically extend a page criterion to responses, exports, or diagrams, or use it to alter canonical titles or labels.

## Local Contextual Citations

Contextual source-page citations in page bodies are an optional instance-local editorial criterion, not a universal requirement. Without an approved criterion, the page's configured source references provide provenance: do not add body citations, and do not treat existing ones as nonconformity or remove them automatically. If an instance adopts a criterion, it defines where and how citations appear; keep it in the local authoring reference. Every source page linked in a body must also appear among the page's configured source references. This option does not require creating an authoring reference when no criterion has been adopted. Creating or changing the criterion follows the governed maintenance workflow in `maintenance.md`.
