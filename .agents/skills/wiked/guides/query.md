# Query

Load this guide only to answer from consolidated operational knowledge.

## Boundaries

- Use only Markdown with a configured operational-content role as evidence. The configured context governs vocabulary and the optional local authoring reference governs representation; neither supplies operational facts.
- Do not inspect ingestion material, archived local sources, tickets, external URLs, YAML, D2, or agent instructions to complete an answer.
- Rendered diagrams may aid reading but never override or complete canonical Markdown.
- Do not change files except to produce an explicitly requested PDF, DOCX, SVG, or PNG through `export.md`.
- A gap remains a limitation. Do not fill it with general knowledge or unmarked inference.
- Query and read-only review do not require a grill.

## Navigate

1. Read the configured context file and root index, but not the optional local authoring reference.
2. Select only relevant top-level indexes.
3. Follow their page links and relevant internal references.
4. Use text search only when progressive navigation cannot locate the subject.
5. Stop when evidence is sufficient or cannot support a reliable answer.

## Answer

- Write in the configured instance language and preserve its canonical terms.
- Distinguish current operation, change proposals, pending questions, and limitations using the labels configured by the instance.
- End with a list of the wiki pages actually consulted, using their titles and relative links.
- Add a limitations section for insufficient, conflicting, or explicitly qualified evidence.
- Make a human-readable document self-contained and list provenance source pages at the end instead of scattering citations through its body.
